### Generic building blocks
This guide contains the generic building blocks for information standards in the Dutch healthcare system. The generic building blocks are meant to model and exchange information from different health related use cases in a uniform way. For this purpose, the EHDS specifications, HL7 FHIR and openEHR are used as international standards. In this initial iteration, the EHDS is the leading direction.

At the moment, the methodology for creating generic building blocks is still in development. More information can be found in the [Nictiz Confluence pages](https://nictiz.atlassian.net/wiki/spaces/GBBS/pages/1106149454/Leeswijzer) (in Dutch).

For questions and change requests, the [Nictiz service desk can be used](https://nictiz.atlassian.net/servicedesk/customer/portal/4/group/12).
